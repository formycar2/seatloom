## 你要改的三条(具体、可核)

### 一、别每次重述 `cd`

你的工作目录就是你的 worktree,`bash` 工具本身就在那儿起。
- 需要切目录时,**一次 `cd` 之后用相对路径**,或者用工具自身的路径参数
- 一条命令里能合并就合并(你已经在做,但 `cd X && a; cd Y && b` 这种仍出现)

### 二、别重复读同一文件

- 一次 `read` 拿全,把要看的部分记在结论里
- 需要回头看,**引用你之前记下的行号**,不要重新 read 整份
- `grep -n` 拿行号就够的时候,别 `read` 全文

### 三、批量查询代替逐条

- 同类检查合并成一条命令(用 `;` 或 `&&` 串,或写进一个临时脚本)
- 已经有脚本能一次问完的事(比如分支落后多少、落在哪些目录),别拆成三次 bash

## 验收(可重跑,不是「注意一点」)

1. 同一文件的 `read` 次数:**不超过 2 次**
2. `cd <绝对路径> &&` 这种前缀在一条命令里最多出现 **1 次**
3. 一件事的工具调用数:**控制在 300 以内**(从 582 降下来)
4. 交付说明里给出你自己的计数,例如:
   ```
   grep -c '"name":"read"' <session 文件>
   ```
   或者你用自己的方式数,但要给得出数
