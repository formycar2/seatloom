## 判断标准只有一条

一个功能算"服务某件价值"，不是因为做得好，而是因为**你能通过它感知到那件价值**。
如果诚实的答案是"你感知不到"，这一格就写"现在不服务任何价值"——这是整张表最有用的一格，
因为它标出了工程投入和你实际收益脱节的地方。

五件价值：**V1** 看一次就知道全队在干什么 · **V2** 点任何一样东西看懂它为什么这么做 ·
**V3** 只需你点头的事自己走到你面前 · **V4** 你说过的话和做过的活对得上 ·
**V5** 产品说的和产品做的是同一件事。

## 今天你真能用的

| 功能 | 服务什么 | 你怎么知道 |
|---|---|---|
| **受治理派单收件箱** | V1 | 一屏按席位分组，状态是真的；点一行展开看到完整指令 |
| **验收卡** | V3 | 卡上写着做什么、什么算对、什么打回；只有你点接受才合并 |
| **合并前的门** | V5 | 关于别的派单的结论、或者没通过的结论，合不进来 |
| **你说一句话派活** | V3 | 一句话变成一张可审阅的提议，写清派给谁、依据是什么，确认后才真写 |
| **历史会话回放** | V2 + V4 | 一个会话一个会话读，每句带原文件路径和行号 |
| **知识面板** | V4 | 一条提炼结论带它的置信度和来源行号 |
| **账本时间线** | V2 + V4 | 按顺序读真实发生过什么 |
| **按项目读数据** | V5 | 切换项目，看到的东西真的变 |
| **真假牌子** | V5 | 页面只在背后那次读取成功时才敢标 LIVE |
| **四个表单说存不下** | V5 | 它告诉你刚填的会没，而不是假装存了 |

## 差一半的（路是真的，缺一环）

| 功能 | 缺在哪 |
|---|---|
| **血缘读取模型**（V2） | 已在真库上验过；但把它画出来的界面没合进来，所以你现在还点不进去。**这是产品里最便宜的一大块剩余价值。** |
| **会话与活的关联**（V2/V4） | 后端建好了；没有界面从"这个会话提炼出什么"走进去。 |
| **监督消息**（V4） | 能看到说过什么；但消息不等于待决策义务。给席位发自由文本那条路仍是空壳。 |
| **席位页**（V1） | 看到谁属于哪；但归属不是工作状态。 |
| **实时镜像**（V1） | 看到进程在跑；但进程不是进展。 |
| **工作项**（V1） | 语义工作对象；但它是第二套人群，和派单没连上。 |

## 现在不服务任何价值的（11 样，其中 9 样你能点到）

- **监督概览** —— 指标卡在数别的东西；预算写死 72%；把渲染时钟当"上次同步"。
- **全局跨项目看板** —— 读的是 `MOCK_GLOBAL_SUMMARY`，项目 id 是 p-1/p-2/p-3。
- **工作依赖图（DAG）** —— 读的是假工作流，节点永远空。
- **目标/阶段两条带** —— 明确没有数据来源。
- **收件箱** —— 工作项/交接的子集，"打开详情"是个空动作。
- **Playbook** —— 只是 T7 治理文档的筛选，不是发布过、带版本、能复用的能力。
- **V1 命令栏提议** —— 超时后写死派给 seat-2 再造一个本地工作项；是编的，该退。
- **四个只能存本地的表单**（创建那一半） —— 诚实部分已服务 V5，创建本身还没有。
- **移动伴侣视图** —— 从任何入口都进不去。

## 剩下的是管道（你看不到，但别的价值靠它）

事件写入、派单调度引擎、治理读模型、发现/水合层。它们的价值只通过某个界面显现——
**不要把它们算成价值**，也不要因为它们"做完了"就报价值已交付。

## 三处路线图要改

1. **UM0 从未按写的那样被感知过** —— 它写终端加 IM；镜像是过渡态。可感知内容现在就是 V1。
2. **UM2 在 competing 计数存在前不成立** —— 卡在真话，不在渲染。
3. **§2b 没有任何一条讲 V5** —— 所以页面敢显示写死的 72% 而阶梯还在报进展。

## 要你拍的四件事

1. 打开时默认看全队还是当前项目（现在是项目范围）。
2. 内部记账（记忆/主题）显不显示在第一屏。
3. 什么算"只有你能决定"—— 这条不定，V3 的定义就不完整。
4. 重复入口留哪个、快捷键归谁（动导航前要你同意）。
