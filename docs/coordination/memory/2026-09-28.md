### Launch contract

```
stepcode claude --model "claude-opus-5[1m]"
```

The `[1m]` suffix is **not optional**. Passing `--model` on the command line bypasses
stepgo's `claudeCode1mOptIn` auto-suffix logic; `--model claude-opus-5` boots with a
200k window while `--model "claude-opus-5[1m]"` boots with 1M. Verified by probe:
banner reads `Opus 5 (1M context) with high effort` and the status line reads `0k/1M`.

Model id evidence: `~/.stepgo/cache/models-list-*.json` lists `claude-opus-5` on the
`purpose=code` channel; `~/.stepgo/cache/model-profiles.json` gives it
`contextTokenLimit: 1000000`. The previous global setting `~/.claude/settings.json`
`"model": "opus[1m]"` is a floating alias that matches no `hasPrefixAny` entry in
model-profiles and therefore falls through to upstream resolution — it was replaced at
launch time by the explicit id rather than left to drift.
