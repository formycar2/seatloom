## Decisions

1. GitLab (`zhangxiaolong/seatloom`, project 11428) is the primary repository and
   hosts CI; GitHub (`formycar2/seatloom`) is a mirror.
2. Quality gates are split into FULL (whole tree, baseline already green) and
   RATCHET (changed files only, pre-existing debt grandfathered). Hard gate: a
   red pipeline blocks merge.
3. All dependency sources resolve internally or domestically. The runner reaches
   the public internet but the overseas route is throttled, so Docker Hub,
   npmjs.org, crates.io, static.rust-lang.org and deb.debian.org are all
   replaced. Do not reintroduce a direct overseas fetch.
4. Rust CI runs on a pre-baked image, `rust-seatloom:1.95.0`, built on the amd64
   sponsor workspace and pushed to the internal Harbor. This removes the apt
   install and toolchain download from every job.
5. `main` and `track/infra-foundation` are protected; merges require a green
   pipeline and resolved discussions.
