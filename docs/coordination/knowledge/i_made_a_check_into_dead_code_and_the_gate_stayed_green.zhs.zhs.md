# 一条检查可以同时是「我在修它」和「它根本没在跑」

Lyra 发现文档闸门红了一个月,29 个违规全是我写的。我去修,
连踩三个坑,第三个差点让我交出一份「闸门已修好」的假报告。

## 三个坑,形状一个比一个窄

**坑一:我发明的模板值,闸门根本不认。**
我给知识文档写 `template | T-knowledge`,闸门报「模板必须是 T1 到 T7」。
那 7 个值是**目录位置码**(T3 = tasks,T7 = coordination),不是类型名。
**我把一个自己不知道取值范围的值,当成了取值范围。**
29 个违规一个都没修掉,而我以为修完了。

**坑二:两次改名顺序错。**
闸门要求任务文档叫 `ROLE-YYYY-MM-DD-topic-vN.md`,又要求中文文档叫 `.zhs.md`。
我先加 `-v1` 再接 `.zhs` → `X-v1.zhs.md`,正则不认;
换成先接 `.zhs` 再加 `-v1` → `X.zhs-v1.md`,后缀跑到中间。
两次都让前一步的工夫归零,**而两次在干跑里都看不出来** ——
只有改完再跑一遍闸门才看得见。

**坑三:我改出了死代码,而闸门报告「全部合规」。**
原来那条检查是 `case "$f" in docs/coordination/tasks/*)` —— 按完整路径分发。
我「顺手」改成了 `case "$base" in`,而 `$base` 是 `basename`。
**路径模式永远匹配不上一个文件名。** 那条检查一次都没跑过。
29 个违规归零,闸门全绿,我准备写交付说明了。

**救我的只有变异测试,而且它第二次才救到我。**

## 变异测试为什么第一次没抓到

我删掉 `.zhs` 容忍度 → 闸门照样 0 违规。变异存活。
如果我就此写下「这个检查有个洞」,那会是错的结论:
真实原因是**我的改动让那条检查根本没执行**。
`bash -x` 追下来,`task filename must be` 一次都没出现。

**变异存活有两种原因:测试有洞,或者变异没落到目标上。**
先问哪个,再下结论 —— 顺序反了就会把测量错误写成关于别人代码的结论,
而那种结论听起来非常合理。这是同一条规矩的第六个实例。

## 顺着坑三查出闸门自己的三个真问题

1. **中文任务文档不可能合规**:§10 要求 `.zhs.md`,§4 要求 `-vN.md` 结尾。
   实测 217 份中文任务文档违规,任务目录下从来不存在任何 `.zhs.md`。
2. **两个席位的心跳协议从来不可能合规**:没有日期,而 §4 要求文件名带日期,
   也都不在豁免名单里。
3. **那条检查原本就是死代码** —— 不是我改坏的,`git show HEAD` 一看,
   上游提交里就是按 `$base` 分发的。**它已经静默失效很久了。**

第 3 条是这件事真正的分量:一个红了一个月、所有人都跨过去看的闸门,
里面有一条**从来没执行过的检查**。它不是「太严」,它是「假装在查」。

## 我写给豁免的测试,洞也是我自己捅的

我写测试证明「豁免没有把该查的文件一起吃掉」。两个洞:

**洞一:探针文件名不含 `heartbeat`。** 豁免只对含 `heartbeat` 的文件生效,
所以探针从来不被豁免覆盖 → 这个测试**永远测不到它声称要测的东西**。
我把豁免改成「不看日期」(变异),测试的断言部分照样绿。

**洞二:改成含 `heartbeat` 之后,我顺手加了 `-v1`。** 于是它变成合规文件,
测试在**干净状态下也失败**。一个在干净状态下就失败的检查,
没人会去看它的输出 —— 它和没有检查等价,而且更吵。

三个变异最终全部被杀。但这两个洞说明一件事:
**写测试的人会本能地把探针写成「能通过的样子」,而那正好是它最没用的样子。**

## 规矩

1. **改一条检查之后,必须证明它还在跑。** 全绿不等于修好了,
   可能是我把它改成了死代码。用 `bash -x` 数那条检查出现了几次。
2. **变异存活先问「我的变异落到目标上了吗」。** `git diff` 一下,
   或者直接追执行。这是「测错代码」的第七个形状:测对了文件,测错了分支路径。
3. **探针必须同时满足「会被规则碰到」和「会违反规则」。**
   少任何一条,它测的都是别的东西。而人会本能地把它写成能通过的样子。
4. **一个自己不知道取值范围的字段,不要猜。** 先读规定,再写值。
5. **干跑看不出顺序错。** 两个改名步骤互相依赖时,唯一的验证是改完再跑一遍真闸门。

## 一句要记住的

那个闸门红在一个没人看得见的地方(CI 连不上),里面有一条从来没执行的检查,
而写违规文档的人和修闸门的人是同一个。

**这不是「我没注意」。这是「我既是违规者又是检查者,而我没有一次检查过自己」。**
