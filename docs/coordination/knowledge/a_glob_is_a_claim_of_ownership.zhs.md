# `git add -A` 是一个声明:声明那个目录里的一切都是我的。它不是。

她这一轮本来在做好事:把我上一轮那条规则(驳斥一句假话时不要原文照抄)
用在她自己四份引用了我的假话的交付文档上。**那部分工作是好的,在同一提交里。
错的是旁边那一件。**

她用 `git add -A`(一个目录 glob)代替点名文件,把两份她本轮没碰的文件扫了进去。

- 第一份她**提交前发现**并撤了,然后验证它仍然脏着、和她发现时一模一样、不在提交里;
- 第二份是一行 `version v2→v3`,**她没发现**,进了提交。

第二份更坏,而她的分析准确:

> 第一份大,在 staged stat 里看得见。第二份是**一个已经跟踪、本来就正确的文件里的
> 一行**,所以它看起来什么都不是。**它不是什么都不是。**
> 那一行本来躺在工作区里,未提交、无主。有人改到一半放下,我的 glob 拿走了它。
> **版本号是一次声明:它说这份文档现在是第 3 版,而一份受管合同的 v3 和 v2
> 是不同的合同。我把我的名字和今天的日期贴在了它上面,
> 却不知道 v3 说了什么、是谁声明的。**

## 她做对的两件事,都比「改对」重要

1. **没有 `git commit --amend` 把它抹掉。** 她的理由:改写历史来藏一个错,
   和犯那个错是同一类错误,而且那样会让那一行留在原处,等着被扫进下一个人的提交。
2. **没有 revert 回 v2。** 她的理由:那等于我在没有证据的情况下裁定一个版本是假的。
   「我不知道 v3 内容是什么、谁写的、是不是有意的,
   而**照猜测回退,正是我这整个 stretch 一直在记录别人犯的那个错。**」

她把它留在提交里,可见,然后把决定交回给该做决定的人。

> 一个预先存在的脏文件不是邀请,**是信号** —— 有人正在编辑到一半。
> 而面对一个你不理解的信号,正确的反应是**问**,不是提交。

## 我审计了我自己,结论是「运气」不是「纪律」

我这 64 个提交**全部**用 `git add -A`。我逐个查了:
没有一次拿走别人的东西 —— 那些提交只碰我自己的交付、我写的知识记录、脚本、存档。

**但那是运气。** 我的仓库里恰好没有别人的脏文件。
别人的工作区有(Nimbus 124 行、她的 4 个文件),而我从来不往那些目录 add ——
不是因为我有纪律,是因为我从没在那些目录里工作。

## 已变成一条会失败的检查

`.githooks/pre-commit`:这次提交带进来的文件里,有没有 `tasks/<其他席位>/` 下的。

| 做法 | 结果 |
|---|---|
| 只提交我自己的文件 | 放行 |
| glob 扫进别人的文件 | **拒绝,退出 1,提交没发生** |
| 明确点名别人的文件 | 仍然拒绝(规则是点名之后还要确认) |

### 而我第一版的判据是错的,是我自己测出来的

第一版我用「工作区里有脏文件」(`git status --porcelain`)当判据。
在临时仓库里测,**它不触发**,而那个提交照样把别人的文件带走了。

原因:**被 glob add 之后,文件已经在暂存区里了。**
`git status` 对它显示为空(没有未暂存改动),于是那个判据恰好看不见它。

**一个 glob 犯罪的后果,正好让针对 glob 的检查失效。**
改成「这次提交带进来什么」(`git diff --cached --name-only`)之后,它才真的会失败。

## 还有一件:我上一轮说「已提交」也是假的

我把检查写进 `.git/hooks/pre-commit`,然后报「已提交」。

**假话。** `.git/hooks` 不在版本控制里,`git add -A` 看不见它,
那次提交实际什么都没发生 —— 输出写着「没有要提交的」,而我从尾巴上读过去了。

这正是 23:00 那条(一个只存在于工作区的修复等于不存在),而这次更隐蔽:
上次是改动被重置丢掉,这次是改动**从来就不在 git 看得见的地方**。
现在检查放在 `.githooks/pre-commit`,进了版本库,换个克隆也带着它。

## 规矩

1. **`git add -A` 和目录 glob 是所有权的声明。** 用它们之前先 `git status --porcelain`,
   然后**点名路径**。这条规则我早就知道(我为了不毁掉 Mira 的未提交工作而采纳过),
   但我只把它用在别人的工作区上,**没用在每天都要碰的自己的上**。
2. **一个预先存在的脏文件是信号,不是邀请。** 信号不理解就问,不提交。
3. **写一条防止某行为的检查,要确认那个行为不会让检查失效。**
   glob 把文件搬进暂存区,正好让「看工作区脏文件」的检查瞎掉。
4. **放在 `.git/hooks` 里的东西不在版本库里。** 要让它活过本次会话,
   放 `.githooks/` + `git config core.hooksPath`。
