# SeatLoom

Persistent seats for AI coding teams.

## Vision

SeatLoom turns tool-centric coding sessions into a persistent team of digital teammates.
Instead of manually copy-pasting between terminal windows, you orchestrate stable seats
such as Product Owner, CTO, Engineer, and QA across Codex, Claude Code, Gemini CLI,
GitHub Copilot, Cursor CLI, and other agent runtimes.

## Core ideas

- Persistent seats instead of disposable sessions
- Automatic handoffs instead of manual copy/paste
- Project-wide traceability instead of scattered tool logs
- Skills and memory that compound over time
- Tool-agnostic adapters for heterogeneous coding agents

## Initial scope

- Adapter layer for local and remote coding agents
- Seat control plane and handoff engine
- Unified event timeline and project ledger
- Skill registry, evaluation, and replayable traces
